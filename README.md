# Clases de Programación IDAT

Repositorio con ejercicios y prácticas de las clases de programación en IDAT.

## Contenido

### Ciclo 1 (`Ciclo_1/Python_Basico/`)
- **Python_Básico**: ejercicios y prácticas fundamentales de Python
- Temas: `Tema.1-4`, `Tema.1-4-1`, `Tema.5`, `Tema.6`, `Tema.7`, `Tema.8`, `Tema.9`, `Tema.10`, `Tema.13`

### Ciclo 2 (`Ciclo_2/EDDPOO_II.04.2023-IIE/`)
- **EDDPOO**: Estructuras de Datos y Programación Orientada a Objetos
- `SEMANA1`–`SEMANA7` + `ProyectoPuntoDeVenta/` (Modelo/Vista/Controlador/UI) + `prueba.py`

## Estructura

Cada tema contiene:
- **Ejercicios**: problemas de práctica
- **Practicas**: proyectos y asignaciones
- **Tarea** (solo en algunos temas, ej. Tema.7)

## Tecnologías (verificado en el árbol)

- Python (Ciclo 1 y Ciclo 2; `requirements.txt`: pytest, black, flake8, pandas, numpy, requests, bs4)
- Qt Designer `.ui` en Ciclo 2/SEMANA4-7 (PyQt, no Java ni C/C++ en el árbol actual)
